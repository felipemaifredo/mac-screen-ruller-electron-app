🟠 Alta prioridade / Alto impacto
Feature	Descrição
Screenshot da medição	Cmd+S captura o canvas atual e salva como PNG
Modo Lupa / Zoom Pixel	Ao pressionar uma tecla, exibe um zoom 4x do cursor para medições sub-pixel
Histórico de medições	Salva as últimas N medições no userData para consulta posterior
Exportar medições como CSV/JSON	Exportar todas as medições pinnadas com coordenadas e valores
🟡 Média prioridade / UX
Feature	Descrição
Snapping	Ao segurar Shift, a medição "gruda" em múltiplos de 8px (grid system)
Unidade alternativa (rem/pt)	Togglear a exibição em px, rem ou pt conforme DPI da tela
Atalhos customizáveis	UI para remapear os shortcuts globais
Régua contínua (drag de origem)	Mover o ponto de origem de uma medição ja fixada
Multi-monitor	A toolbar seguir para o display correto ao mudar de tela
Posição persistente da toolbar	Salvar no config.json a última posição da janela flutuante
🟢 Baixa prioridade / Polimento
Feature	Descrição
Sons de feedback	Som sutil ao pinar uma medição (Enter)
Opacidade da overlay configurável	Slider para ajustar o quanto o overlay escurece o fundo
Modo daltônico	Paletas de cor com padrões alternativos
i18n completo	Já tem useI18n — expandir os textos para EN/ES
